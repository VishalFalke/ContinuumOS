# Sprint 2 — Current-State Failure Summary

This compact summary makes the seven Sprint 2 current-state failure themes explicit. These are documented workflow problems and assumptions for the hypothetical portfolio case, not findings from external validation.

| Failure | Where it occurs | Consequence | Current owner visibility | Evidence status |
|---|---|---|---|---|
| Repeated registration | Clinic-to-diagnostic handoff | Reconciliation work and delay | Fragmented | Proposed workflow problem |
| Disconnected records | EHR, diagnostic and referral systems | Teams reconstruct episode history | Unclear | Assumption |
| Acknowledgement delay | Result available but unreviewed | Follow-up may stall | No shared queue | Assumption |
| Unclear ownership | Cross-setting handoff | Task remains unassigned | Poor | Assumption |
| Referral leakage | Referral creation to acceptance | Receiving response is not visible | Fragmented | Assumption |
| Payer delay | Planned escalation | Readiness is discovered late | Separate workflow | Assumption |
| Incomplete follow-up | Patient communication and closure | Next action is not confirmed | Distributed | Assumption |
