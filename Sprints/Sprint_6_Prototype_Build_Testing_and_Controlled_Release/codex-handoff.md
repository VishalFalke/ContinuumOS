# Sprint 6 Codex handoff contract

## Use

Before each implementation task, update or state the exact approved story, linked sources, allowed files, forbidden files, acceptance criteria, test/evaluation cases and verification commands. This file is a task-control template; it does not create scope.

## Current execution boundary

- Active sprint: Sprint 6 only.
- Current completed foundation evidence: ENAB-601 shell only; no screen story is complete.
- Next planned foundation work: ENAB-602 deterministic synthetic fixtures/state-event logic, then ENAB-603 shared accessible workflow components.
- Forbidden unless separately approved: future-sprint work, deferred requirements FR-23/FR-26/FR-28, live integrations, source write-back, real AI, authentication, production data and architecture changes.

## Task contract template

| Control | Record before implementation |
|---|---|
| Exact task and story | ID, sprint increment and user-approved request |
| Included sources | Only the Sprint 5/6 artifacts required by that story |
| Allowed files | Smallest expected code, fixture, test and evidence files |
| Forbidden files | User-owned/unrelated work, future-sprint files, generated/production/secrets files |
| Acceptance and safety | Linked ACs, authority, prohibited actions, safe return and audit event |
| Verification | Available commands, scenario/manual checks and evidence location |
| Stop conditions | Ambiguity/conflict, scope change, security/privacy/AI-safety change, repeated verification failure |

## Handoff format

Report the following, stating `None` where applicable: files changed; files created; files deleted (only if explicitly approved); approved features implemented; tests added/updated; commands run and actual results; dependencies added; assumptions; known limitations; security-sensitive areas touched; AI-safety controls touched; open questions; unresolved defects; state/evidence files updated; open risks/blockers; and the exact next recommended story. Do not say complete solely because the page renders.
