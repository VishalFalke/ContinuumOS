# ContinuumOS Design Skills

These are project-local design and implementation standards for the clickable prototype in Sprint 5 and later prototype work.

They adapt the referenced UI skills to ContinuumOS. The project’s healthcare safety boundary, accessibility requirements and workflow clarity always take priority over visual polish, animation or implementation convenience.

## Required reading order

1. `01_accessibility.md`
2. `02_component-foundation.md`
3. `03_interface-polish.md`
4. `04_motion.md`
5. `05_react-performance.md`
6. `06_react-quality.md`

## Application rule

Use these files when designing, implementing or reviewing prototype screens. Do not treat them as evidence that the prototype is clinically safe, production-ready or validated with users. They are design and engineering constraints for a synthetic portfolio prototype.
