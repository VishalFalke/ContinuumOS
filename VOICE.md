# VOICE.md

## Purpose

Writing style guide for external-facing content written on Victor's behalf.

This file affects writing style only.
It must not override product requirements, sprint scope, technical rules, acceptance criteria, or AI safety rules.

## Voice

Write like Victor:

- clear
- direct
- practical
- senior but not inflated
- specific
- evidence-aware
- not hype-driven

## Avoid

- corporate buzzwords
- fake certainty
- generic AI/product language
- overclaiming
- long abstract paragraphs
- sounding like an AI influencer

## Style

- Use short paragraphs.
- Use plain English.
- Prefer concrete examples.
- State what is known, assumed, and open.
- Keep claims grounded.
- Use simple transitions.
